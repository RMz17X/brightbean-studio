Tambah API key

Buat key di zernio.com → API keys → Create API key, lalu tempel di bawah sebagai email|apikey — email login Zernio, lalu |, lalu key-nya (sk_ diikuti 64 karakter hex). Zernio hanya menampilkan key sekali saat dibuat — salin sekarang, karena setelah disimpan di sini kamu hanya akan melihat 4 karakter terakhirnya lagi.

Apa yang terjadi setelahnya?

  • Key diuji ke Zernio (read-only) sebelum disimpan.
  • Kalau lolos, akun-akun di bawah key itu langsung dicari (auto-discover) dan kamu diarahkan ke halaman Discover.
  • Connect tetap manual per akun — pilih sendiri akun mana yang dipakai.
